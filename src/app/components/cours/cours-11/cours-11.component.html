Résumé du cours

Les différents types de champs HTML de type choix (checkbox, radio, select) se lient très facilement aux formulaires réactifs d'Angular en utilisant la directive `formControlName`.

1. Les cases à cocher (Checkbox)

Une case à cocher se lie à une valeur booléenne (`true`/`false`) : 

        HTML
        <input type="checkbox" formControlName="newsletter" />

2. Les boutons radio (Radio)

Pour des boutons radio exclusifs, on applique le même `formControlName` sur chaque bouton. Angular sélectionne la radio dont le tag HTML `value` correspond à la valeur actuelle du `FormControl` : 

        HTML
        <input type="radio" value="male" formControlName="gender" /> Homme
        <input type="radio" value="female" formControlName="gender" /> Femme

3. Les listes déroulantes (Select)

Le tag <select> porte la directive `formControlName`, tandis que chaque balise <option> spécifie sa valeur via son attribut `value` (ou `[value]` si la valeur provient d'un tableau d'éléments du TS) : 

        HTML
        <select formControlName="framework">
          <option value="" disabled>Choisir...</option>
          
            <option *ngFor="let fw of frameworks" [value]="fw">{{ '{{' }} fw {{ '}}' }}</option>
          
          
            @for (fw of frameworks; track fw) {
              <option [value]="fw">{{ '{{' }} fw {{ '}}' }}</option>
            }
          
        </select>

Conclusion

types de bindings :
Les checkboxes, radios et dropdowns utilisent le même attribut `formControlName`, simplifiant grandement la récupération des valeurs côté TypeScript.
Valeur initiale :
Il est possible d'affecter une valeur initiale par défaut dès le constructeur (ex: `new FormControl('male')` ou `new FormControl(false)`).
