Le composant est l'unité de base d'Angular. Maîtrisez le décorateur @Component et la structuration des templates.

Résumé du cours

Un composant Angular = une classe TypeScript + un template HTML + des styles CSS. Le décorateur @Component lie ces trois fichiers ensemble.

1. Anatomie d'un composant

import { Component, OnInit } from '@angular/core';

@Component({
  selector:    'app-user-card',  ← nom du tag HTML
  templateUrl: './user-card.component.html',
  styleUrls:  ['./user-card.component.css'],
})
export class UserCardComponent implements OnInit {
  public userName: string = 'Alain';
  public userAge: number = 42;

  public ngOnInit(): void {
    console.log('Composant initialisé');
  }
}

2. Types de selectors

'app-user' Selector élément → <app-user></app-user>
'[appTooltip]' Selector attribut → <div appTooltip>
'.card-highlight' Selector classe CSS → <div class="card-highlight">

3. Template inline vs externe

// Template inline (petits composants)
@Component({
  selector: 'app-badge',
  template: `<span class="badge">{{ '{{' }} label {{ '}}' }}</span>`,
  styles: [`.badge { background: #4f46e5; }`]
})
export class BadgeComponent {
  label = 'Nouveau';
}

4. ViewEncapsulation

Par défaut, Angular encapsule les styles d'un composant pour éviter les fuites de CSS.

import { ViewEncapsulation } from '@angular/core';

@Component({
  encapsulation: ViewEncapsulation.Emulated,  ← défaut : styles scopés
  encapsulation: ViewEncapsulation.None,      ← styles globaux
  encapsulation: ViewEncapsulation.ShadowDom, ← vrai Shadow DOM
})

À retenir

Génération CLI

Créer un composant :

ng g c components/user-card

Composant inline (pas de fichiers séparés) :

ng g c badge --inline-template --inline-style

Fichiers générés

user-card.component.ts — logique

user-card.component.html — template

user-card.component.css — styles scopés

user-card.component.spec.ts — tests

💡 Bonne pratique

Un composant = une responsabilité. Si votre composant dépasse 200 lignes, c'est probablement le signe qu'il faut le découper en sous-composants.

Conclusion

Le composant est la cellule vivante d'Angular. Chaque interface utilisateur, aussi complexe soit-elle, se décompose en un arbre de composants aux responsabilités clairement délimitées. La maîtrise du décorateur @Component et de ses options (selector, encapsulation, changeDetection) vous donnera un contrôle total sur la façon dont Angular instancie, affiche et met à jour vos vues.
