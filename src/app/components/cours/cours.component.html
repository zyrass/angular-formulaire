ℹ️ Angular v17 vs. v18+ & v20

Ce cours est conçu sous Angular 17 avec une architecture classique basée sur les Modules (NgModule). La majorité des projets professionnels en production utilisent encore ces fondations.

📁 Modules (v17) vs. Standalone (v18+)

Depuis v18, le mode standalone est activé par défaut. Savoir déclarer ReactiveFormsModule dans un module reste indispensable pour maintenir les applications d'entreprise.

⚡ Flux d'événements (control.events)

Angular 18+ introduit control.events pour suivre précisément les interactions. Sur Angular 17, on utilise valueChanges et statusChanges.

💡 Vers Angular 20

Les versions récentes mettent l'accent sur les Signals pour la réactivité fine. Les formulaires réactifs fondamentaux (FormGroup, FormControl) restent identiques.
