Résumé du cours

Pour structurer des formulaires complexes de manière logique (par exemple, regrouper les informations de contact ou d'adresse), Angular permet d'imbriquer des `FormGroup` au sein d'un `FormGroup` parent.

1. Déclaration du modèle imbriqué

Dans la classe TypeScript, on instancie un `FormGroup` en lui passant un autre `FormGroup` comme valeur de l'une de ses clés : 

        TS
        public form = new FormGroup({
          username: new FormControl('', Validators.required),
          address: new FormGroup({
            street: new FormControl('', Validators.required),
            city: new FormControl('', Validators.required)
          })
        });

2. Directive `formGroupName` dans le Template

Dans le code HTML, on utilise la directive `formGroupName` sur un élément conteneur (comme une <div> ou un <fieldset>) pour informer Angular du changement de scope/contexte. Les contrôles internes restent référencés par `formControlName` : 

        HTML
        <form [formGroup]="form">
          <input formControlName="username" />
          
          <div formGroupName="address">
            <input formControlName="street" />
            <input formControlName="city" />
          </div>
        </form>

3. Accéder aux contrôles imbriqués

On utilise la syntaxe pointée pour cibler un contrôle imbriqué : `form.get('parent.enfant')` : 

        TS
        const cityControl = this.form.get('address.city');

Conclusion

formGroupName :
Indispensable pour lier le modèle imbriqué défini dans le TypeScript avec le DOM, permettant de garder une logique de structure propre et modulaire.
Structure de données :
`form.value` reflète directement la hiérarchie déclarée. C'est parfait pour modéliser des objets complexes prêts à être consommés par une API REST.
