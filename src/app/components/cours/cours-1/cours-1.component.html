Résumé du cours

Dans Angular, il existe deux approches principales pour la création de formulaires :

Formulaire basé sur un modèle (Template-Driven) :
Dans cette approche, la logique du formulaire est principalement définie dans le fichier de modèle HTML. Il faut spécifier les règles de validation directement dans le modèle et Angular infère la structure du formulaire à partir de celui-ci.
Formulaire basé sur les données (Data-Driven) :
Ici, la logique du formulaire est principalement définie dans le composant TypeScript. Il faut explicitement créer les contrôles de formulaire dans le code TypeScript et définir les règles de validation et comportements associés.

Le FormGroup est un des fondamentaux de la construction de formulaires sur Angular. Il regroupe plusieurs contrôles de formulaire tels que les FormControl et les FormArray. De plus, il peut également contenir d'autres FormGroup, permettant une organisation hiérarchique des données du formulaire. 

        template HTML
        <form (ngSubmit)="submitForm()">
          // ... Le contenu du formulaire ici ...
        </form>
      
        component TS
        // ... Dans la classe ...
        public submitForm() {} // Permet d'éviter le crash de l'application en l'initialisant

Démarrage de l'Application (Bootstrapping) :

La façon dont une application Angular démarre et configure les dépendances globales a grandement évolué : 

          main.ts (v17)
          import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';
          import { AppModule } from './app/app.module';

          platformBrowserDynamic().bootstrapModule(AppModule)
            .catch(err => console.error(err));
        
          main.ts (v18)
          import { bootstrapApplication } from '@angular/platform-browser';
          import { AppComponent } from './app/app.component';

          bootstrapApplication(AppComponent)
            .catch(err => console.error(err));
        
          main.ts (v19+)
          import { bootstrapApplication } from '@angular/platform-browser';
          import { AppComponent } from './app/app.component';
          import { provideExperimentalZonelessChangeDetection } from '@angular/core';

          bootstrapApplication(AppComponent, {
            providers: [
              provideExperimentalZonelessChangeDetection() // Démarrage léger sans Zone.js
            ]
          }).catch(err => console.error(err));

Conclusion

(ngSubmit) :
C'est un événement déclenché lors de la soumission du formulaire. Il faut lier cette action à une fonction dans le composant TypeScript.
submitForm() :
C'est la fonction à exécuter lorsque le formulaire est soumis. Elle est définie dans la classe TypeScript pour centraliser la logique de soumission de l'application.
