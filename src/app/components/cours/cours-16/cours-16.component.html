Résumé du cours

L'optimisation des performances est au cœur des versions v17+. L'introduction des Deferrable Views permet de différer le chargement et le rendu de parties lourdes du template. En parallèle, l'avènement du mode Zoneless permet de se passer de Zone.js pour de meilleures performances de rendu.

1. La syntaxe Deferrable Views (v18+)

Les blocs `@defer` permettent de spécifier des conditions de déclenchement (`on viewport`, `on idle`, `on hover`, `when condition`) : 

@defer (on viewport) {
  <app-heavy-chart />
} @loading {
  <p>Chargement du composant...</p>
} @placeholder {
  <div>Zone réservée au graphique</div>
} @error {
  <p>Échec du chargement</p>
}

2. Passage au mode Zoneless

Pour activer la détection réactive fine sans Zone.js, on configure le bootstrap de l'application dans `app.config.ts` : 

export const appConfig: ApplicationConfig = {
  providers: [
    provideExperimentalZonelessChangeDetection()
  ]
};

Conclusion

L'utilisation conjointe des Deferrable Views et des architectures Zoneless révolutionne les performances de vos applications Angular. En scindant vos modules lourds en chunks chargés uniquement au survol ou à la visibilité, et en limitant les cycles de rendu aux seuls signaux ayant muté, vous offrez à vos utilisateurs une réactivité proche des 60 FPS sans effort de développement supplémentaire.
