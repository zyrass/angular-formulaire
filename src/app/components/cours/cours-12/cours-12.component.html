Résumé du cours

L'interface ControlValueAccessor (CVA) fait office de pont entre un composant personnalisé Angular et l'API des formulaires réactifs ou template-driven. Elle permet à un composant personnalisé de se comporter exactement comme un input natif.

1. Les 4 méthodes clés

  • writeValue(value: any) : Appelée par Angular pour écrire une nouvelle valeur depuis le modèle vers la vue (le composant).
  • registerOnChange(fn: any) : Enregistre une fonction de rappel à exécuter lorsque la valeur change dans le composant (met à jour le modèle).
  • registerOnTouched(fn: any) : Enregistre une fonction de rappel à appeler lorsque le composant reçoit le focus puis le perd (touched).
  • setDisabledState(isDisabled: boolean) : (Optionnelle) Appelée par Angular lorsque le statut d'activation du contrôle change.

2. Implémentation du composant

En v17/v18, la déclaration requiert l'enregistrement du token NG_VALUE_ACCESSOR avec forwardRef : 

          TS (v17/v18)
          @Component({
            selector: 'app-star-rating',
            providers: [
              {
                provide: NG_VALUE_ACCESSOR,
                useExisting: forwardRef(() => StarRatingComponent),
                multi: true
              }
            ]
          })
          export class StarRatingComponent implements ControlValueAccessor {
            // Implémentation des 4 méthodes...
          }

En v19/v20, on utilise les Signal inputs pour lier les états et simplifier le cycle de rendu sans Zone.js : 

          TS (v19/v20)
          export class StarRatingComponent implements ControlValueAccessor {
            // Utilisation de read-only signals pour piloter l'UI
            public disabled = signal(false);
            
            setDisabledState(isDisabled: boolean): void {
              this.disabled.set(isDisabled);
            }
          }

En v21, le ControlValueAccessor fusionne avec les signaux bidirectionnels (model()), supprimant le boilerplate d'enregistrement manuel du ValueAccessor : 

          TS (v21)
          export class StarRatingComponent {
            // Liaison bidirectionnelle native basée sur les signaux
            value = model(0); 
            disabled = input(false);
          }

Conclusion

Le ControlValueAccessor est l'outil indispensable pour briser les limites des champs de formulaire standards d'HTML. Qu'il s'agisse d'un sélecteur de notation, d'une palette de couleur personnalisée ou d'un calendrier imbriqué, CVA assure que votre composant restera nativement compatible avec les API de validation et les directives de formulaires Angular.
