Résumé du cours

Afin d'utiliser le module lié aux formulaires réactifs, je dois importer obligatoirement le module ReactiveFormsModule qui provient de @angular/forms. 

          app Module (v17)
          import { ReactiveFormsModule } from '@angular/forms';

          @NgModule({
            declarations: [ // ... des components ... ],
            imports: [ // ... des modules ..., ReactiveFormsModule],
            providers: [provideClientHydration()],
            bootstrap: [AppComponent],
          })
        
          Component Standalone (v18+)
          import { Component } from '@angular/core';
          import { ReactiveFormsModule } from '@angular/forms';

          @Component({
            selector: 'app-form',
            standalone: true,
            imports: [ReactiveFormsModule],
            templateUrl: './form.component.html'
          })
          export class FormComponent {}

Pour la partie HTML, là où le formulaire est utilisé, dans le tag <form>, il faut placer la directive [formGroup]="form" qui sera bindée à un attribut portant le nom de "form" du composant TS. 

        template HTML
        <form (ngSubmit)="submitForm()" [formGroup]="form">
          // ... Le contenu du formulaire ici ...
        </form>

Ci-dessous, le début du composant avec l'import de FormGroup et FormControl depuis @angular/forms. 

        component TS
        // ... des imports ...
        import { FormControl, FormGroup } from '@angular/forms';

        // ... dans la classe ...
        public form: FormGroup; // attribut
        public submitForm() {}  // méthode

La logique se passe dans le composant. Il s'agit d'ajouter tous les contrôles que je souhaite gérer en assignant une nouvelle instance de FormGroup à l'attribut `form` et en lui passant un objet dont les clés correspondent à chaque contrôle. 

        component TS
        // ... dans la classe ...
        public form: FormGroup = new FormGroup({
          lastname: new FormControl(''),
          firstname: new FormControl(''),
          passPhrase: new FormControl(''),
        })

Pour lier chaque input à sa clé correspondante dans le template HTML, on utilise la directive formControlName : 

        template HTML
        <form (ngSubmit)="submitForm()" [formGroup]="form">
          <div class="form-group flex flex-col p-2">
            <label class="font-bold mb-1">Nom :</label>
            <input formControlName="lastname" type="text" class="rounded-md" />
          </div>
          <div class="form-group flex flex-col p-2">
            <label class="font-bold mb-1">Prénom :</label>
            <input formControlName="firstname" type="text" class="rounded-md" />
          </div>
          // ... etc ...
        </form>

Conclusion

ReactiveFormsModule :
Ce module est indispensable au bon fonctionnement des formulaires réactifs.
[formGroup]="form" :
Binding d'une directive extrêmement importante où je lie l'attribut form de mon component qui est du type FormGroup.
new FormGroup({}) :
Instanciation de la classe FormGroup en lui passant un objet qui contient toutes les clés liées aux inputs, chacune instanciée par une classe FormControl.
formControlName="x" :
Liaison de l'input HTML avec la clé du FormGroup définie dans la classe TypeScript.
