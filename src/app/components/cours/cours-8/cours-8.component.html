Résumé du cours

Le `FormArray` est une alternative au `FormGroup` utilisé pour gérer un nombre variable de contrôles (champs dynamiques).

1. Initialisation

Dans le composant TS, on déclare le `FormArray` contenant une liste initiale de contrôles : 

        TS
        public form = new FormGroup({
          hobbies: new FormArray([
            new FormControl('', Validators.required)
          ])
        });

2. Accéder et manipuler le tableau

Pour simplifier la manipulation dans le Template, on déclare un getter pour caster la structure en `FormArray` : 

        TS
        get hobbies() {
          return this.form.get('hobbies') as FormArray;
        }
        
        addHobby() {
          this.hobbies.push(new FormControl('', Validators.required));
        }
        
        removeHobby(index: number) {
          this.hobbies.removeAt(index);
        }

3. Binding dans le Template HTML

On associe le container parent à `formArrayName`, puis on boucle sur `hobbies.controls` en liant chaque contrôle individuel à l'attribut dynamique `[formControlName]="i"` (où `i` est l'index de la boucle) : 

          HTML (v17 - ngFor)
          <div formArrayName="hobbies">
            <div *ngFor="let control of hobbies.controls; let i = index">
              <input [formControlName]="i" />
              <button (click)="removeHobby(i)">Supprimer</button>
            </div>
          </div>
        
          HTML (v18+ - @for)
          <div formArrayName="hobbies">
            @for (control of hobbies.controls; track $index) {
              <div>
                <input [formControlName]="$index" />
                <button (click)="removeHobby($index)">Supprimer</button>
              </div>
            }
          </div>

Conclusion

FormArray :
Excellent outil pour gérer des questionnaires, listes de tags, ou tout élément modifiable à la volée par l'utilisateur final.
Indice dynamique :
L'index `i` de la boucle `*ngFor` sert de `formControlName` pour que chaque input soit relié de manière unique et indexée dans le tableau.
