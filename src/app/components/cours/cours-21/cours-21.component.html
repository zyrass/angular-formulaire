{{ title }}

Transformez les données directement dans le template — pipes natifs, pipes asynchrones et pipes personnalisés.

Résumé du cours

Un pipe est une fonction pure de transformation appelée directement dans le template avec l'opérateur |. Les pipes n'altèrent jamais la donnée source — ils retournent une nouvelle valeur transformée.

1. Pipes natifs essentiels

<!-- Texte -->
<p>{{ 'angular' | uppercase }}</p>        <!-- ANGULAR -->
<p>{{ 'ANGULAR' | lowercase }}</p>        <!-- angular -->
<p>{{ 'hello world' | titlecase }}</p>     <!-- Hello World -->

<!-- Nombres -->
<p>{{ 1234.5 | number:'1.2-2' }}</p>     <!-- 1 234,50 -->
<p>{{ 0.75 | percent:'1.0-0' }}</p>     <!-- 75% -->
<p>{{ 49.9 | currency:'EUR':'symbol' }}</p> <!-- 49,90 € -->

<!-- Date -->
<p>{{ today | date:'dd/MM/yyyy HH:mm' }}</p>
<p>{{ today | date:'longDate':'':'fr' }}</p>

<!-- Objets -->
<pre>{{ user | json }}</pre>             <!-- JSON.stringify -->
<p>{{ longText | slice:0:100 }}...</p>   <!-- Tronquer -->

2. Le pipe async — Observables & Promises

// Dans le composant
public users$: Observable<User[]> = this.userService.getAll();

<!-- Dans le template : souscription + désinscription auto -->
<ul>
  <li *ngFor="let u of users$ | async">{{ '{{' }} u.name {{ '}}' }}</li>
</ul>

3. Pipe personnalisé

@Pipe({ name: 'truncate' })
export class TruncatePipe implements PipeTransform {
  transform(value: string, limit = 50): string {
    return value.length > limit ? value.substring(0, limit) + '...' : value;
  }
}

<!-- Utilisation -->
<p>{{ description | truncate:100 }}</p>

À retenir

Pipes chaînés

{{ name | uppercase | slice:0:10 }}

Les pipes s'appliquent de gauche à droite.

Génération CLI

ng g pipe shared/pipes/truncate

Pure vs Impure

Un pipe pur (défaut) ne recalcule que si la référence change. Un pipe impure (pure: false) recalcule à chaque détection de changement — à éviter.

Conclusion

Les pipes sont un outil élégant pour garder la logique de formatage hors du composant TypeScript. Le pipe async est particulièrement précieux pour gérer les Observables en évitant les fuites mémoire. Créez vos pipes personnalisés pour toute transformation répétée — c'est l'approche DRY par excellence en Angular.
