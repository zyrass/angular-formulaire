Résumé du cours

Les validateurs dans Angular sont des fonctions qui évaluent la valeur d'un contrôle et retournent soit une liste d'erreurs, soit `null` si le contrôle est valide.

1. Les Validateurs Synchrones Intégrés

Angular fournit un ensemble de validateurs prêts à l'emploi regroupés dans la classe Validators :

  • Validators.required : Le champ ne doit pas être vide.
  • Validators.email : La valeur doit respecter le format d'une adresse email.
  • Validators.min(value) : La valeur numérique doit être supérieure ou égale à `value`.
  • Validators.minLength(length) : Le nombre de caractères doit être supérieur ou égal à `length`.

2. Déclaration dans le TypeScript

Les validateurs sont passés en **deuxième paramètre** du constructeur de `FormControl`. S'il y en a plusieurs, on les regroupe dans un tableau : 

        TS
        import { FormControl, FormGroup, Validators } from '@angular/forms';

        public form = new FormGroup({
          email: new FormControl('', [Validators.required, Validators.email]),
          age: new FormControl('', [Validators.required, Validators.min(18)])
        });

3. Vérification de l'état : `.valid` `toSignal(statusChanges)` `validSignal`

On peut vérifier si l'ensemble du formulaire ou un contrôle spécifique est valide grâce à la propriété d'état : 

          TS (v17/v18)
          if (this.form.valid) {
            // Soumettre le formulaire
          }
        
          TS (v19/v20)
          import { toSignal } from '@angular/core/rxjs-interop';
          import { map } from 'rxjs/operators';

          // Conversion de l'état de validation en Signal
          public isValid = toSignal(
            this.form.statusChanges.pipe(map(s => s === 'VALID')),
            { initialValue: this.form.valid }
          );
        
          TS (v21)
          // Utilisation directe du Signal de validation natif
          if (this.form.validSignal()) {
            // Soumettre le formulaire
          }

4. Les Validateurs Asynchrones

Contrairement aux validateurs synchrones, les validateurs asynchrones retournent une **Promise** ou un **Observable**. Pendant la validation, l'état du contrôle passe temporairement à PENDING : 

          TS (v17-v20)
          email: new FormControl('', {
            validators: [Validators.required, Validators.email],
            asyncValidators: [this.checkEmailUnique]
          })
        
          TS (v21)
          // Les signaux natifs permettent de suivre le statut PENDING en direct
          @if (emailCtrl.pendingSignal()) {
            <span>Validation asynchrone en cours...</span>
          }
