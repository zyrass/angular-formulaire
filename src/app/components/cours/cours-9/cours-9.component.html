Résumé du cours

Le service `FormBuilder` est un sucre syntaxique d'Angular qui permet de générer des formulaires complexes de façon beaucoup plus concise. Il évite de répéter le mot-clé `new` pour chaque `FormGroup`, `FormControl` ou `FormArray`.

1. Injection du service : Constructeur Fonction `inject()` `SignalFormBuilder`

La façon d'obtenir l'instance du FormBuilder varie selon la version d'Angular : 

          TS (v17 - constructor)
          constructor(private fb: FormBuilder) {}
        
          TS (v18-v20 - inject)
          import { inject } from '@angular/core';
          import { FormBuilder } from '@angular/forms';

          private fb = inject(FormBuilder);
        
          TS (v21 - SignalFormBuilder)
          import { inject } from '@angular/core';
          import { SignalFormBuilder } from '@angular/forms';

          private sfb = inject(SignalFormBuilder);

2. Comparatif de Syntaxe

Sans FormBuilder (Verbeux)

this.form = new FormGroup({
  name: new FormControl('', Validators.required),
  hobbies: new FormArray([
    new FormControl('')
  ])
});

Avec FormBuilder (Concise)

this.form = this.fb.group({
  name: ['', Validators.required],
  hobbies: this.fb.array([['']])
});

3. Déclarations simplifiées

  • `this.fb.group({ ... })` instancie un `FormGroup`.
  • `this.fb.array([ ... ])` instancie un `FormArray`.
  • `['', Validators.required]` instancie un `FormControl` avec sa valeur initiale et ses validateurs.

Conclusion

FormBuilder :
Ce service permet d'alléger considérablement l'écriture du TypeScript lorsque vous configurez des formulaires massifs.
