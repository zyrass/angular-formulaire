Les 4 mécanismes de liaison données-vue : interpolation, property binding, event binding et two-way binding.

Résumé du cours

Le Data Binding est le mécanisme qui synchronise le composant TypeScript avec son template HTML. Angular propose 4 types de liaisons selon la direction du flux de données.

{{ '{{' }} interpolation {{ '}}' }}

Affiche une valeur TypeScript dans le HTML

<p>Bonjour {{ '{{' }} userName {{ '}}' }} !</p>
<p>Total : {{ '{{' }} price * quantity {{ '}}' }}</p>

[property] binding

Lie une propriété DOM à une expression TS

<img [src]="userAvatar" />
<button [disabled]="isLoading">...

(event) binding

Écoute un événement DOM et appelle une méthode

<button (click)="onSave()">Sauver</button>
<input (keyup)="onKey($event)">

[(two-way)] binding

Synchronisation bidirectionnelle avec ngModel

<input [(ngModel)]="email" />
// Équivalent à :
<input [ngModel]="email"
       (ngModelChange)="email=$event">

Binding de classe et style

// Class binding unique
<div [class.active]="isActive">...</div>

// Objet de classes
<div [ngClass]="{ active: isActive, error: hasError }">

// Style binding
<p [style.color]="isError ? 'red' : 'green'">...</p>
<div [ngStyle]="{ fontSize: size + 'px', color: color }">

$event : l'objet événement

// Récupérer la valeur d'un input
<input (input)="onInput($event)">

public onInput(e: Event) {
  const val = (e.target as HTMLInputElement).value;
}

⚠️ FormsModule requis

Le two-way binding avec [(ngModel)] nécessite d'importer FormsModule dans votre module Angular.

Conclusion

Les quatre mécanismes de data binding forment la grammaire fondamentale du langage de templates Angular. Une fois ces syntaxes maîtrisées, la communication entre votre logique TypeScript et votre vue HTML devient naturelle et intuitive. L'essentiel est de bien comprendre le sens du flux : unidirectionnel (TS→HTML ou HTML→TS) ou bidirectionnel pour les formulaires simples.
