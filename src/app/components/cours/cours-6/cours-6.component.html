Résumé du cours

Chaque contrôle de formulaire est représenté par un objet étendant `AbstractControl` qui maintient un ensemble de drapeaux (flags) d'états. De plus, Angular applique automatiquement des classes CSS correspondant à ces états sur les balises ``.

1. Les couples d'états d'un contrôle

Visite (Focus)

  • 🟢 touched : Le champ a perdu le focus au moins une fois.
  • 🔴 untouched : Le champ n'a jamais perdu le focus.

Modification (Ecriture)

  • 🟢 dirty : L'utilisateur a modifié la valeur.
  • 🔴 pristine : La valeur n'a pas été modifiée.

2. Classes CSS injectées par Angular

Angular applique dynamiquement des classes CSS sur les éléments HTML liés aux contrôles :

  • `ng-touched` / `ng-untouched`
  • `ng-dirty` / `ng-pristine`
  • `ng-valid` / `ng-invalid`

3. Exemple d'utilisation en CSS

On peut par exemple appliquer une bordure rouge uniquement aux champs invalides et déjà visités : 

        CSS
        input.ng-invalid.ng-touched {
          border: 2px solid red;
        }

Formulaire

Interagissez avec le champ pseudo pour voir ses états basculer instantanément.

Accès aux drapeaux ( Propriétés Classiques toSignal() wrapper Signals Natifs ) :

touched : ctrl.touched toSignal(touched$) ctrl.touchedSignal() = {{ form.get('nickname')?.touched }}
dirty : ctrl.dirty toSignal(dirty$) ctrl.dirtySignal() = {{ form.get('nickname')?.dirty }}
valid : ctrl.valid toSignal(valid$) ctrl.validSignal() = {{ form.get('nickname')?.valid }}

Conclusion

Classes automatiques :
Les classes `ng-valid`, `ng-invalid`, etc., permettent de modifier l'apparence des champs via le CSS global du projet sans aucune logique TypeScript.
Bordures réactives :
En liant la classe CSS avec `form.get('nickname')?.touched`, on s'assure d'un retour visuel de validation propre et discret pour l'utilisateur.
