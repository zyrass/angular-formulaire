{{ title }}

Configurez les routes, naviguez programmatiquement et lisez les paramètres d'URL avec ActivatedRoute.

Résumé du cours

Le Router Angular permet de créer des applications multi-vues sans rechargement de page. Il mappe des chemins URL à des composants et gère l'historique du navigateur.

1. Configuration des routes

// app-routing.module.ts
const routes: Routes = [
  { path: '', component: HomeComponent, pathMatch: 'full' },
  { path: 'users', component: UserListComponent },
  { path: 'users/:id', component: UserDetailComponent },
  { path: 'admin', loadChildren: () =>
    import('./admin/admin.module').then(m => m.AdminModule) },
  { path: '**', component: NotFoundComponent }  ← wildcard
];

2. Navigation dans le template

<!-- Lien simple -->
<a routerLink="/users" routerLinkActive="active-link">Utilisateurs</a>

<!-- Avec paramètres dynamiques -->
<a [routerLink]="['/users', user.id]">{{ '{{' }} user.name {{ '}}' }}</a>

<!-- Avec query params -->
<a [routerLink]="['/search']" [queryParams]="{ q: 'angular' }">Chercher</a>

<!-- Point d'injection du composant actif -->
<router-outlet></router-outlet>

3. Navigation programmatique

private router = inject(Router);
private route  = inject(ActivatedRoute);

// Navigation simple
this.router.navigate(['/users']);

// Avec paramètres
this.router.navigate(['/users', userId], {
  queryParams: { tab: 'profile' }
});

// Lire les paramètres
this.route.paramMap.subscribe(params => {
  const id = params.get('id');
});

À retenir

Routes enfants

{
  path: 'admin',
  component: AdminComponent,
  children: [
    { path: 'users', component: ... },
    { path: 'stats', component: ... },
  ]
}

Lazy Loading

Chargez les modules uniquement quand l'utilisateur navigue vers la route. Réduit drastiquement le bundle initial.

💡 Conseil

Utilisez snapshot pour lire les params une seule fois, et paramMap (Observable) si la route peut changer sans destruction du composant.

Conclusion

Le Router Angular est un système complet de navigation côté client. La configuration déclarative des routes, couplée au lazy loading et aux guards, vous permet de construire des SPA performantes et sécurisées. Maîtrisez ActivatedRoute pour extraire les paramètres et Router pour naviguer programmatiquement depuis vos services ou handlers.
